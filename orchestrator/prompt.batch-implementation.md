# Implement one batch ticket

Use the following ticket and applicable parent requirements as the source of truth. Implement the behavior and write or revise its tests together. Run the configured tests, fix failures and commit the ticket delta locally. If a reviewer requests rework, address the finding in code, tests, or both. Return the commit and a concise account of the checks, or the concrete blocker. The host constructs and tests a prospective integration commit and collects independent reviews. Leave batch refs, publication and delivery to the host.
